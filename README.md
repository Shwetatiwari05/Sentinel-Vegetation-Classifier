# Sentinel Vegetation Classifier

Sentinel Vegetation Classifier is an AI/ML-based remote sensing application that detects and classifies vegetation/grass from Sentinel-2 satellite imagery. The system retrieves Sentinel-2 Surface Reflectance data through Google Earth Engine, processes the Red and Near-Infrared (NIR) bands, and calculates NDVI (Normalized Difference Vegetation Index) as an additional vegetation feature. It uses multiple machine learning models — Random Forest, SVM, and a 2D CNN — to perform pixel-level or patch-based vegetation classification. Users can select a geographical location and date range through the web interface, after which the backend fetches the satellite imagery, runs the selected ML model, and generates vegetation predictions, grass percentage, confidence, mean NDVI, and a visual grass-detection map. The project demonstrates an end-to-end pipeline combining satellite remote sensing, Google Earth Engine, machine learning, deep learning, and a web-based prediction interface.
